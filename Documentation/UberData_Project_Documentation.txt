1. EXECUTIVE SUMMARY AND OBJECTIVE
--------------------------------------------------------------------------------
This project delivers an enterprise-grade analytics solution built on 150,000 Uber trip booking records. The primary objective is to analyze urban marketplace dynamics, quantify conversion funnel leakages, diagnose cancellation drivers, evaluate vehicle fleet unit economics, and size lost Gross Merchandise Value across an interactive multi-page Power BI executive reporting suite.

The pipeline spans raw data hygiene in Microsoft Excel, automated data cleansing in Python, relational data warehousing in MySQL, exploratory data analysis, dimensional modeling, custom DAX engineering, and executive dashboard design.


2. TECHNICAL ARCHITECTURE AND PIPELINE BREAKDOWN
--------------------------------------------------------------------------------

A. Data Hygiene, Auditing, and Preprocessing - Microsoft Excel and Power Query
   - Audited the raw 150,000-row tabular dataset across 21 operational columns.
   - Handled missing and placeholder string indicators across customer ratings, driver ratings, cancellation reasons, and vehicle turnaround times.
   - Applied TRIM and CLEAN logic to remove invisible whitespace and non-printable characters across dimensions.
   - Used XLOOKUP to map vehicle types to business segments and commission structures.
   - Replaced blank cancellation and incomplete indicators with numeric 0 flags, setting reason descriptions for completed trips to Not Applicable.
   - Verified totals and referential integrity across status categories prior to database ingestion.

B. Database Warehousing and SQL Analytical Views - MySQL 8.0
   - Designed the primary staging table bookings with targeted data types including VARCHAR, DECIMAL, INT, DATE, TIME, and indexing on high-cardinality fields.
   - Implemented analytical queries resolving volume distribution, cancellation reasons, distance tiers, and vehicle yield economics.
   - Built the centralized reporting view v_fact_trips to encapsulate business transformations, temporal dimensions, and derived metrics like fare per kilometer.

C. Statistical Profiling and Exploratory Data Analysis - Python
   - Ran automated exploratory analysis scripts using Pandas, NumPy, Matplotlib, and Seaborn.
   - Produced statistical summaries across numerical metrics including VTAT, CTAT, booking value, ride distance, and ratings.
   - Conducted correlation auditing revealing near-zero correlation between ride distance and fare value, confirming that nominal fares remain flat across trip distances while yield per kilometer scales inversely with distance.

D. Semantic Data Modeling and Star Schema - Power BI Desktop
   - Structured the reporting data model using Kimball dimensional modeling principles:
       * Fact Table: FactTrips containing 150,000 records
       * Dimension Table: DimDate containing full calendar attributes
       * Dimension Table: DimVehicle containing vehicle tiers, capacity, and market segments
   - Established single-direction one-to-many relationships with referential integrity.
   - Created Distance Tier and CSAT Tier calculated columns with numeric sort-by-column keys to ensure logical visual sorting.


3. COMPLETE DAX FORMULA REPOSITORY
--------------------------------------------------------------------------------

Total Bookings = COUNTROWS[FactTrips]

Completed Rides = 
CALCULATE[
    COUNTROWS[FactTrips],
    FactTrips[booking_status] = "Completed"
]

Failed Bookings = 
CALCULATE[
    COUNTROWS[FactTrips],
    KEEPFILTERS[FactTrips[booking_status] <> "Completed"]
]

Completion Rate Pct = 
DIVIDE[[Completed Rides], [Total Bookings], 0]

Failure Rate Pct = 
DIVIDE[[Failed Bookings], [Total Bookings], 0]

Driver Cancellation Rate Pct = 
DIVIDE[
    CALCULATE[
        COUNTROWS[FactTrips],
        FactTrips[booking_status] = "Cancelled by Driver"
    ],
    [Total Bookings],
    0
]

Customer Cancellation Rate Pct = 
DIVIDE[
    CALCULATE[
        COUNTROWS[FactTrips],
        FactTrips[booking_status] = "Cancelled by Customer"
    ],
    [Total Bookings],
    0
]

Total Completed Revenue = 
CALCULATE[
    SUM[FactTrips[booking_value]],
    FactTrips[booking_status] = "Completed"
]

Average Fare per Ride = 
DIVIDE[[Total Completed Revenue], [Completed Rides], 0]

Avg Fare per KM = 
DIVIDE[
    [Total Completed Revenue],
    CALCULATE[
        SUM[FactTrips[ride_distance]],
        FactTrips[booking_status] = "Completed"
    ],
    0
]

Estimated Lost GMV = 
VAR BenchmarkFare = 
    CALCULATE[
        [Average Fare per Ride],
        ALL[FactTrips[booking_status]]
    ]
RETURN
    [Failed Bookings] * BenchmarkFare

Average Trip Distance = 
CALCULATE[
    AVERAGE[FactTrips[ride_distance]],
    FactTrips[booking_status] = "Completed"
]

Average VTAT = 
CALCULATE[
    AVERAGE[FactTrips[avg_vtat]],
    NOT[ISBLANK[FactTrips[avg_vtat]]]
]

Average CTAT = 
CALCULATE[
    AVERAGE[FactTrips[avg_ctat]],
    FactTrips[booking_status] = "Completed"
]

Severe Pickup Delay Rate Pct = 
DIVIDE[
    CALCULATE[
        COUNTROWS[FactTrips],
        FactTrips[avg_vtat] > 15
    ],
    CALCULATE[
        COUNTROWS[FactTrips],
        NOT[ISBLANK[FactTrips[avg_vtat]]]
    ],
    0
]

Average Customer Rating = 
CALCULATE[
    AVERAGE[FactTrips[customer_rating]],
    NOT[ISBLANK[FactTrips[customer_rating]]]
]

Average Driver Rating = 
CALCULATE[
    AVERAGE[FactTrips[driver_ratings]],
    NOT[ISBLANK[FactTrips[driver_ratings]]]
]
